# 第二套独立 Go 插件规格

仅迁移第二套，第一套配置逐项保持不变。第二套保留 OPENCODE_API_KEY 密钥引用，使用独立路由 opencode-go-second，设置显示 OpenCode Go · 2。使用官方导出的 PiAiAdapter 与原生 Go provider，不复制、修改核心代码、不包含 app.asar 绝对导入。内置备用目录包含 38 个模型，运行目录通过手动点击查询已认证接口更新，保留每个模型的协议、能力和兼容设置，按真实聊天 sessionId 发送请求。通过 LLM 注册、设置与发现接口接入。模型发现使用第二套已保存密钥或编辑草稿密钥，只访问固定 Go 地址；新模型资料从 models.dev 的 Go 目录自动获取，不猜测接口；仅点击“获取可用模型”时刷新列表，保存后只改本连接模型列表；启动、定时和密钥更新不触发查询，失败不改已保存配置。迁移时备份并移除旧核心覆盖，原生适配器继续拥有第一套和其他现有路由。更改仅涉及本插件、profile 清单、第二套与默认模型的路由名称。每次请求捕获配置快照，历史、工具、图片、取消、错误处理复用官方适配器。
