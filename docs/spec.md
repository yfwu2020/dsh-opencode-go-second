# 第二套独立 Go 插件规格

仅迁移第二套，第一套配置逐项保持不变。第二套保留 OPENCODE_API_KEY 密钥引用，使用独立路由 opencode-go-second，设置显示 OpenCode Go · 2。使用官方导出的 PiAiAdapter 与原生 Go provider，不复制、修改核心代码、不包含 app.asar 绝对导入。模型目录包含已认证接口返回的 38 个模型，保留每个模型的协议、能力和兼容设置，按真实聊天 sessionId 发送请求。通过 LLM 注册、设置与发现接口接入。模型发现使用第二套已保存密钥或编辑草稿密钥，只访问固定 Go 地址；未知模型资料不得被猜测，发现失败不改配置。迁移时备份并移除旧核心覆盖，原生适配器继续拥有第一套和其他现有路由。更改仅涉及本插件、profile 清单、第二套与默认模型的路由名称。每次请求捕获配置快照，历史、工具、图片、取消、错误处理复用官方适配器。
